# Jerry R. Napier

**Systems automation and digital asset reliability engineer building local-first tools, verifiable data pipelines, and safe operational workflows.**

I turn messy operational environments into understandable systems: observable automation, evidence-backed metadata, bounded recovery, reproducible diagnostics, and interfaces that make the safe action the obvious action.

My background spans digital asset management, media archives, metadata operations, data governance, and workflow engineering. I work primarily with Python, PowerShell, SQL, JSON/XML, and Windows automation.

## How I build

- Local-first when privacy, reliability, or operator control matters
- Dry-run and fail-closed behavior before mutation
- Explicit ownership and identity checks before process control
- Structured evidence, hashes, and reconciliation instead of optimistic assumptions
- Bounded retries and recovery with visible operator handoff
- Honest documentation of safety boundaries, limitations, and test evidence
