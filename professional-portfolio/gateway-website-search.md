# Gateway Website Search

**Help customers find the right service or support page using words they already know.**

Gateway’s website serves visitors looking for products, help, and account access. Its **Find** panel brings those starting points together. Visitors can browse public links or search the catalog from the same panel.

[Try Find on the Gateway website](https://gatewayinformationgroup.com/)

## Try three searches

1. Open **Find** and search for `GTI` to locate Gateway’s transaction review service.
2. Search for `order help` to find **Contact**.
3. Search for `my orders` to find the public entrance to the member portal.

## What the design demonstrates

People rarely search using the exact name on a menu. The search recognizes common abbreviations and everyday support phrases. Results point to a clear next step, whether the visitor wants to explore a service, ask for help, or sign in.

## Evidence and boundaries

The November 26, 2026 release checks covered public search routing in Chromium at desktop and mobile widths. The November 27 showcase review confirmed that the public homepage still presents Find and its catalog search. This is a case study with a hosted demonstration. Its evidence covers public navigation. Signed-in account activity, accessibility certification, and changes in customer outcomes remain outside the review.
