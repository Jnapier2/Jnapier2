## Interactive analytics example

[Account Analyst Portfolio Showcase](account-analytics/README.md) is a browser adaptation of existing Excel portfolio work. Its [page](account-analytics/index.html) and [calculation module](account-analytics/analytics.js) use twelve synthetic records for client lookup, spend classification, savings summaries, and missing-input review. The README explains how to run it locally. It is separate from the original workbook and is not a hosted production service.

## Evidence and rights

The linked case studies describe version-specific evidence. Historical test counts are qualification records, not a current production guarantee. Public repository workflows provide dated, commit-specific results. The two private implementations are represented by documentation, not downloadable applications.

Data Contract Monitor uses Apache-2.0. Workflow, Policy Navigator, and Operations Intelligence use their repositories' portfolio review licenses. The private case studies and synthetic analytics example follow the profile repository's rights notice. Public visibility does not itself grant an open-source license.
