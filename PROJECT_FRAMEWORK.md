# Reliable Project Delivery Framework

**Public edition:** v1.8.0 · **Type:** Documentation

This public overview describes the qualities used to evaluate the portfolio: useful outcomes, clear evidence, understandable controls, and honest limitations. Individual projects document the behavior they actually demonstrate.

## Evaluation criteria

- **Usefulness:** A clear problem, intended audience, and reviewable deliverable.
- **Evidence:** Results tied to an identified version, dataset, and test scope.
- **Usability:** Understandable setup, controls, feedback, and limitations.
- **Reliability:** Appropriate error handling, data preservation, and recovery.
- **Privacy:** Suitable demonstration data and clear licensing and access boundaries.

The [review checklist](PROJECT_FRAMEWORK_CHECKLIST.md) supports evaluation of the public material. [Metadata](PROJECT_FRAMEWORK_METADATA.json) identifies this documentation edition, and the [changelog](PROJECT_FRAMEWORK_CHANGELOG.md) records its current scope.

This overview is not a software product, certification, or claim that every project passes every criterion. Project repositories and case studies contain their own evidence and limitations.
