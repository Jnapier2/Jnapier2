# Portfolio Review Checklist

**Public edition:** v1.8.0

- [ ] The project identifies its audience and practical purpose.
- [ ] A reviewer can find the stated source, demonstration, report, or case study.
- [ ] Synthetic data and illustrative results are labeled.
- [ ] Version-specific test results state their scope and limitations.
- [ ] Setup instructions and relevant usage restrictions are available.
- [ ] Rights, attribution, and source availability are clear.

These are review criteria, not evidence that a project has passed them. See the [public overview](PROJECT_FRAMEWORK.md).
