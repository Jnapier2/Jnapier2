# Reliable Project Delivery Framework — Changelog

## v1.6.0 — 2026-08-17

**Source baseline:** ChatGPT New Thread Project Parameters v2.17.9

This release advances the public framework without publishing the private master
package or account-level prompts.

### Added

- An explicit evidence and instruction hierarchy.
- Critical/High/Normal/Optional triage and coverage-ledger requirements.
- Project-wide file inventory and capability consolidation.
- Exact-duplicate grouping by hash and functional-overlap review by behavior.
- Reference mapping and count/size/rollback reporting before file retirement.
- Critical-input assurance: recognized, validated, mapped, exercised, confirmed.
- Release identity and managed-file integrity before sensitive startup.
- A deterministic, redacted, read-only Export20 contract.
- Dependency, SBOM, provenance, data-classification, and security boundaries.
- Trading, mining, long-running automation, and public-edition risk controls.
- A practical implementation checklist, machine-readable metadata, and CI tests.

### Clarified

- Computer recognition is advisory and never a cross-computer ownership gate.
- Cloud storage is source/handoff/archive rather than live runtime.
- A newer filename or private version does not automatically replace public or
  known-good authority.
- Completion reports distinguish verified, unverified, deferred, blocked,
  skipped, and not-found work.

## v1.5.0 — 2026-08-15

**Source baseline:** ChatGPT New Thread Project Parameters v2.17.6

Initial public principles document covering canonical project identity,
project-local portability, known-good preservation, reversible changes, critical
input validation, release identity, independent computers, operator control,
privacy-conscious diagnostics, and transparent releases.

## Public versioning boundary

The public framework and the private parameter package use separate version
numbers. A private package update does not automatically become a public release;
the public framework advances only after its reusable principles are reviewed,
sanitary for publication, and validated in this repository.
